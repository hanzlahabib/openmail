# Code of Conduct

## Our pledge
We want participation in OpenMail MCP to be respectful and harassment-free for everyone, regardless of background or experience level.

## Expected behaviour
- Be kind and constructive; critique code and ideas, not people.
- Assume good faith; ask before assuming.
- Respect others' time and privacy. Never share private mail content or credentials.

## Unacceptable behaviour
- Harassment, discrimination, insults, threats, or unwelcome sexual attention.
- Publishing others' private information.
- Sustained disruption of discussions or reviews.

## Enforcement
Maintainers may edit or remove contributions and restrict participation that violates this code. Report concerns privately to the maintainers (contact: TODO(owner): set a conduct contact before the public release). Reports are handled confidentially.

## Scope
This applies in project spaces (issues, pull requests, discussions) and when representing the project publicly.
